# 조용한 루미큐브

AI와 혼자 바로 연습하거나, 최대 4명이 같은 네트워크에서 즐길 수 있는 실시간 루미큐브 게임입니다. 외부 패키지 없이 Node.js 18 이상에서 실행됩니다.

## 실행

```powershell
npm start
```

브라우저에서 `http://localhost:4173`을 열고 `AI와 바로 플레이`를 선택하면 대기실 없이 즉시 연습전을 시작합니다. 사람과 함께할 때는 방을 만든 뒤 초대 링크 또는 6자리 코드로 참가하세요. 다른 기기에서 접속하려면 서버를 실행한 컴퓨터의 사설 IP와 `4173` 포트를 사용하면 됩니다.

## 포함된 규칙

- 홈에서 즉시 시작하는 1인 AI 연습전과 2~4명 멀티플레이\n- 106 타일(4색 × 1~13 × 2장 + 조커 2장), 각 14장 배분\n- AI도 사람과 같은 서버 규칙 검증을 거쳐 수를 내거나 타일을 뽑음
- 같은 숫자의 서로 다른 색 3~4장 / 같은 색 연속 숫자 3장 이상
- 첫 등록은 본인 손패만으로 30점 이상
- 등록 후 보드 재배치 가능, 단 매 턴 손패 타일 1장 이상 제출
- 조커의 대체 숫자·색을 서버가 저장하고 모든 최종 조합을 서버에서 검증
- 뽑기는 1장 후 턴 종료, 풀 소진 뒤 모두 패스하면 종료
- 방장이 대기실에서 30초 단위(30~600초)의 턴 시간을 설정
- 시간 종료 시 초안은 되돌아가며, 편집 중이었다면 3장 / 아니면 1장을 자동으로 뽑음

## 테마

화면 오른쪽 위에서 `기본`과 `스프레드시트` 테마를 전환할 수 있습니다. 선택은 각 브라우저에만 적용되어 같은 방의 다른 플레이어 화면에는 영향을 주지 않습니다.

## 설계 메모

서버는 상대 손패와 덱 순서를 절대 보내지 않습니다. 편집 중인 보드는 현재 턴인 플레이어에게만 보이는 개인 초안이며, 제출할 때만 검증 및 공유됩니다.
